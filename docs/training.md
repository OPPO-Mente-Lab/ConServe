# Training

The model path used for OPSD is the output of M3 supervised fine-tuning (SFT) of [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B). Model weights and training data are not part of this repository. The steps below prepare the data and launch SFT using a local model copy.

## 1. Build M3 SFT data

Supply images and matching inference `__vlm.json` outputs (see [data formats](data_formats.md#13-vlm-result-json-output)). The builder filters OCR/VLM disagreements with the included `training/hallucination_filter.py`, constructs numbered multi-box images, and writes `manifest_train.jsonl` and `manifest_eval.jsonl`.

```bash
export CONSERVE_ROOT="$(pwd)"  # run from the ConServe repository root
export SFT_DIR=/path/to/m3_sft_data
python training/build_sft_m3_datapairs.py \
  --vlm-dirs /path/to/vlm_outputs \
  --image-dir /path/to/images \
  --out-dir "$SFT_DIR"
python training/export_sft_llamafactory.py --sft-dir "$SFT_DIR"
```

The export writes `llamafactory_data/dataset_info.json` and the two ShareGPT JSON files. Image paths point to the `samples/` directory generated by the builder. The input images and inference outputs remain outside this repository.

## 2. Train the M3 checkpoint

Install a [LLaMA-Factory](https://github.com/hiyouga/LLaMA-Factory) checkout with Qwen3.5 multimodal support in the same Python environment as this project. Download [Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B) to a local directory as shown in the [quick start](../README.md#quick-start).

```bash
export LLAMAFACTORY_ROOT=/path/to/LLaMA-Factory
git clone https://github.com/hiyouga/LLaMA-Factory.git "$LLAMAFACTORY_ROOT"
pip install -e "$LLAMAFACTORY_ROOT"
export MODEL_PATH=/path/to/Qwen3.5-9B
export SFT_DATA_DIR="$SFT_DIR/llamafactory_data"
export SFT_OUTPUT_DIR=/path/to/m3_sft_checkpoint
bash "$CONSERVE_ROOT/training/train_m3_sft.sh"
```

The launcher uses full SFT, the `qwen3_5_nothink` multimodal template, and DeepSpeed ZeRO-2 by default. It freezes the vision tower while training the language model and multimodal projector. Set `NNODES`, `N_GPUS_PER_NODE`, `PER_DEVICE_BATCH_SIZE`, `GRAD_ACC` and `SFT_EPOCHS` for your allocation; the default is one node with eight GPUs. `SFT_DRY_RUN=1` prints the command after checking the model, data and DeepSpeed config paths.

When training finishes, use the exported Hugging Face checkpoint directory as `STUDENT_MODEL` for OPSD. The OPSD launcher sets `TEACHER_MODEL` to the same directory unless an alternative is supplied.
