# Scene Fit Notes

Use this reference only when the input includes explicit scene or audience context.

## Register

- Public guidance should be clear and neutral.
- Educational text should be simple and readable.
- Professional text may use domain wording when it remains understandable.
- Child-facing text should avoid dense or formal phrasing.

## High-risk Readability

- Prioritize comprehension for warnings, permissions, safety, legal, medical, and public instruction text.
- Critical severity requires that the fluency issue materially blocks or distorts understanding.
- If the text is only mildly awkward but understandable, keep it Minor.
