# Background Error Taxonomy

- `smearing_artifact`: brushed, melted, or smeared reconstruction.
- `color_discontinuity`: local hue, brightness, saturation, or color-block mismatch.
- `gradient_discontinuity`: interrupted, stepped, reversed, or abrupt gradient.
- `texture_discontinuity`: unnatural break in directional or structured texture.
- `hard_inpainting_edge`: artificial hard boundary around the repair.
- `inpainting_residue`: non-readable source outline, shadow, halo, or fragment remains.
- `scene_element_damage`: subject, object, icon, decoration, contour, or meaningful line is deformed.
- `missing_scene_content`: non-text source content is erased.
- `unexpected_generated_content`: unsupported object, shape, semantic content, or false shadow is introduced.
- `pattern_repetition_artifact`: cloned or tiled motifs reveal repetitive reconstruction.

Readable source glyph residue belongs to Text Rendering. Clear translated text in the wrong place belongs to Layout.
